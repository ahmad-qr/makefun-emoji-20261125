# Entry notes — One Emoji, One Smile

Bounty: https://make.fun/bounty/u-0xkianno-one-emoji-one-smile-5470751f

The emoji (1 character, exactly one emoji):

> 😊

Why this emoji: a single smiling face — warm and friendly at first glance,
read the same way by a stranger of any age or background, with no irony or
in-joke that could land wrong.

The program (`main.py`, stdlib only) writes exactly this emoji to
`/output/entry.txt` and asserts the gate itself: 1–8 characters, exactly
one emoji, not only white space. It is deterministic — the same bytes on
every run.
